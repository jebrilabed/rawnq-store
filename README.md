# 🛋️ متجر رونق (RAWNQ Home & Living)

منصة تجارة إلكترونية عصرية متكاملة وشاملة، تجمع بين واجهة متجر تفاعلية فائقة السرعة ومتعددة اللغات، ولوحة تحكم وإدارة تنفيذية متطورة لإدارة المنتجات، الطلبات، المخزون، والشحن التلقائي.

المشروع مبني بالكامل بأحدث إصدارات **Next.js 14 (App Router)**، **React 18**، و **TypeScript**، معتمدًا على أسلوب تصميم نقي بـ **CSS Modules** بدون أي أطر عمل خارجية ثقيلة، ومربوط بقاعدة بيانات **PostgreSQL** عبر **Prisma ORM**.

## ✨ المميزات الرئيسية

### 1. واجهة المتجر للعملاء (Storefront)
* 🌐 **دعم كامل لـ 4 لغات عالمية ومحلية:**
  - العربية (`ar` - الافتراضية)
  - الإنجليزية (`en`)
  - العبرية (`he`)
  - الروسية (`ru`)
  - مع تبديل تلقائي كامل لاتجاه النصوص والواجهة (**RTL / LTR**) وترجمة فورية للمصطلحات، الأقسام، والمنتجات.
* 🎨 **تصميم مخصص فائق الأناقة والسرعة:**
  - شريط إعلانات متحرك (**Marquee Bar**).
  - سكك تصفح متحركة وتفاعلية للأقسام والمنتجات (**Category Rail & AutoScrollRail**).
  - شريط تنقل تقدمي ذكي (**Navigation Progress Bar**) وشاشات تحميل هيكلية لطيفة (**Skeleton Loaders**) لتحسين تجربة التصفح (UX).
* 🗂️ **تصنيفات هرمية متعددة المستويات (Hierarchical Categories):**
  - دعم التصنيفات الرئيسية والفرعية المتداخلة مع روابط التتبع السريع (Breadcrumbs).
* 🔍 **بحث وفلترة ذكية:**
  - بحث فوري في الكتالوج، وفرز وتصفية المنتجات حسب الأقسام والتصنيفات.
* 🛍️ **صفحات منتجات تفاعلية ومتكاملة:**
  - معاينة صور عالية الدقة.
  - محدد متغيرات المنتج (**Variant Picker**): اختيار الألوان والمقاسات والأحجام مع تتبع لحظي للكميات المتبقية لكل خيار.
  - عرض أسعار المقارنة (Compare At Price) ونسب التخفيضات.
* ❤️ **قائمة المفضلة والرغبات (Wishlist):**
  - حفظ المنتجات المفضلة وربطها بحساب العميل مع تحديث فوري للحالة.
* 🛒 **سلة تسوق محلية محمية (Smart Cart):**
  - سلة مشتريات تفاعلية ومحفوظة، مع تنقية وفحص آلي للمدخلات لمنع أي تلاعب بالأسعار أو الكميات.
* 💳 **عملية إتمام طلب سلسة ومحمية (Checkout):**
  - احتساب رسوم التوصيل تلقائياً وفقاً للمنطقة المحددة (الضفة، القدس، مناطق الداخل).
  - دعم الشحن المجاني الذكي عند تجاوز قيمة الطلب للحد الأدنى المحدد في الإعدادات.
  - خيارات دفع مرنة: الدفع عند الاستلام (**COD**) أو التحويل البنكي مع إمكانية رفع إيصال السداد مباشرة.
  - معالجة الطلب عبر خادم مؤمّن (**Server Actions**) داخل معاملة ذرية تضمن عدم تجاوز المخزون.
* 📦 **تتبع الطلبات وسجل الحالات (Order Timeline):**
  - خط زمني تفاعلي يبين دورة حياة الطلب (جديد ⬅️ قيد المعالجة ⬅️ قيد الشحن ⬅️ تم التوصيل).
  - صفحة تأكيد طلب مفصلة مع إمكانية استعراض الفاتورة وتتبع بوليصة الشحن.
* 👤 **حسابات العملاء (Customer Portal):**
  - تسجيل الدخول وإنشاء حساب عميل مؤمن بالكامل.
  - إدارة البيانات الشخصية، العناوين الافتراضية، ومتابعة سجل الطلبات السابقة.
* 📄 **صفحات محتوى ديناميكية (`/page/[slug]`):**
  - صفحات تفاعلية لمحتوى المتجر: «من نحن»، «سياسة التوصيل»، و«الأسئلة الشائعة» (FAQ).

### 2. لوحة التحكم والإدارة (Admin Dashboard)
* 🔐 **بوابة إدارة محمية (`/admin`):**
  - مدخل مستقل للمديرين عبر `/admin-login`، مع تحقق أمني إلزامي في الخادم وقاعدة البيانات من رتبة المدير (`ADMIN`).
* 📊 **نظرة عامة ومؤشرات أداء:**
  - ملخص فوري للطلبات الجديدة، حالة الإرساليات، ومؤشرات المخزون.
* 📦 **إدارة المنتجات (CRUD):**
  - إضافة، تعديل، حذف، ونشر المنتجات.
  - إدارة المتغيرات (الألوان، المقاسات، أسعار المتغيرات، والمخزون المخصص).
  - إضافة الترجمات بجميع اللغات المدعومة لكل منتج.
  - رفع الصور مباشرة إلى خوادم Cloudinary مع فحص الحجم والامتدادات.
* 🗃️ **إدارة الأقسام والتصنيفات الشجرية:**
  - بناء شجرة تصنيفات لانهائية المستويات، مع منع برمجي للعلاقات الدائرية (Cycle Prevention).
* 📈 **مراقبة وإدارة المخزون (Inventory Management):**
  - مراقبة سريعة ومباشرة للمخزون مع تنبيهات عند وصول المنتج إلى الحد الأدنى للمخزون (**Low Stock Threshold**).
* 🚚 **إدارة الطلبات والربط اللوجستي مع Best Route:**
  - استعراض الطلبات وفلاتر الحالات، مع فحص إيصالات التحويل البنكي المرفوعة من العملاء.
  - فحص الاتصال التفاعلي مع واجهة شركة الشحن Best Route API.
  - إرسال وتوليد إرساليات الشحن تلقائياً أو يدوياً بنقرة زر، ومتابعة رقم التتبع (Tracking Number) وحالات الإرسال والردود الواردة من مزود الشحن.
* 📍 **إدارة مناطق وأسعار التوصيل (Delivery Areas):**
  - تحديد وتعديل رسوم الشحن لكل منطقة وتسمياتها بمختلف اللغات وترتيب ظهورها.
* 📝 **إدارة المحتوى والأسئلة الشائعة (Store Content):**
  - تعديل محتوى صفحات "من نحن" و"التوصيل" وإدارة الأسئلة الشائعة وترجماتها.
* ⚙️ **إعدادات المتجر العامة:**
  - تعديل اسم المتجر، أرقام التواصل والواتساب، حساب إنستغرام.
  - ضبط خيارات الدفع وتفاصيل الحسابات البنكية (اسم الحساب ورقم الـ IBAN).
  - تحديد رسوم الشحن الافتراضية وحد الشحن المجاني، وحد التحذير لنقص المخزون.

## 🔒 الأمان وموثوقية البيانات

1. **تشفير كلمات المرور (Scrypt):**
   - تُشفر جميع كلمات المرور عبر `crypto.scrypt` باستخدام **Salt عشوائي فريد** بطول 16 بايت لكل مستخدم، مما يجعلها منيعة ضد هجمات جداول قوس قزح (Rainbow Tables).
2. **عزل الصلاحيات وحماية الإدارة:**
   - الدخول إلى لوحة التحكم (`/admin`) محمي بالكامل؛ يتم فحص جلسة المستخدم والتحقق المباشر من امتلاكه رتبة `ADMIN` في قاعدة البيانات مع كل طلب Server Action.
3. **سلامة العمليات المالية والمخزون (Atomic Transactions):**
   - إنشاء الطلب وحسم المخزون يتمان داخل معاملة واحدة ذرية (`prisma.$transaction`)؛ إن فشل حسم المخزون لأي عنصر يتم التراجع عن الطلب فوراً لمنع البيع الزائد (Overselling).
4. **حماية التسعير وحسابات السلة:**
   - يتم احتساب أسعار المنتجات ورسوم الشحن بالكامل على الخادم من قاعدة البيانات مباشرة، متجاهلاً أي تعديل أو تلاعب في أسعار عناصر السلة من جهة المتصفح.
5. **سكريبت آمن لإنشاء المديرين:**
   - توفير سكريبت مخصص لإنشاء حساب المدير في الطرفية مع كتابة كلمة المرور مخفية لضمان عدم ظهورها في سجل الأوامر.

## ⚙️ المتغيرات البيئية (Environment Variables)

أنشئ ملفاً باسم `.env.local` في المجلد الرئيسي للمشروع، واملأ المتغيرات التالية وفقاً للنموذج الموضح في `.env.example`:

```env
# رابط الموقع الأساسي
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# روابط قاعدة البيانات (يفضل استخدام Supabase أو Neon)
# رابط الـ Connection Pooler للعمليات العادية
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/postgres?sslmode=require&pgbouncer=true
# الرابط المباشر للـ Migrations وتطبيق Prisma
DIRECT_URL=postgresql://USER:PASSWORD@HOST:5432/postgres?sslmode=require

# سر تشفير جلسات Auth.js (نص عشوائي طويل)
AUTH_SECRET=your-super-strong-random-secret-key

# إعدادات Cloudinary لرفع وإدارة الصور
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=your-api-key
CLOUDINARY_API_SECRET=your-api-secret

# بيانات تكامل الشحن مع Best Route (اختياري / يُملأ عند تفعيل الشحن الآلي)
BEST_ROUTE_LOGIN=your-best-route-username
BEST_ROUTE_PASSWORD=your-best-route-password
BEST_ROUTE_DB=best-route
BEST_ROUTE_ORDER_TYPE_ID=your-order-type-id
```

> [!IMPORTANT]
> لا تقم برفع ملفات `.env` أو `.env.local` إطلاقاً إلى مستودعات Git للحفاظ على سرية مفاتيحك وبيانات الاتصال.

## 🚀 دليل التثبيت والتشغيل (Quick Start)

### المتطلبات المسبقة:
- بيئة تشغيل **Node.js** (إصدار 18.18.0 أو أحدث).
- قاعدة بيانات **PostgreSQL** نشطة وجاهزة للاتصال.

### خطوات التثبيت:

1. **تثبيت حزم المشروع:**
   ```bash
   npm install
   ```

2. **تجهيز متغيرات البيئة:**
   انسخ ملف `.env.example` إلى `.env.local` وقم بملء بيانات قاعدة البيانات والخدمات:
   ```bash
   cp .env.example .env.local
   ```

3. **تطبيق مخطط قاعدة البيانات:**
   لإنشاء الجداول والفهارس في قاعدة البيانات باستخدام Prisma:
   ```bash
   npm run db:push
   ```

4. **زرع البيانات الأولية للمتجر (Seeding):**
   لإنشاء الأقسام، المنتجات الافتراضية، مناطق الشحن ومحتوى المتجر:
   ```bash
   npm run db:seed
   ```

5. **فحص سلامة الاتصالات الخارجية:**
   تأكد من نجاح الاتصال بقاعدة بيانات PostgreSQL وبوابة Cloudinary:
   ```bash
   npm run db:check
   ```

6. **إنشاء أول حساب مدير للمتجر:**
   شغّل السكريبت الآمن وأدخل البريد الإلكتروني وكلمة المرور (من 8 إلى 128 حرفاً، تُكتب مخفية):
   ```bash
   npm run admin:create
   ```

7. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   افتح المتصفح على [http://localhost:3000](http://localhost:3000) لتصفح المتجر، أو [http://localhost:3000/admin-login](http://localhost:3000/admin-login) لتسجيل الدخول إلى لوحة التحكم.

## 🗺️ خريطة المسارات والصفحات (Application Routes)

### مسارات المتجر (`src/app/[locale]/(store)`):
- `/[locale]` — الصفحة الرئيسية (عروض، أقسام، منتجات مختارة).
- `/[locale]/products` — استعراض كافة المنتجات مع البحث والفلترة.
- `/[locale]/products/[id]` — تفاصيل المنتج، اختيار المتغيرات وإضافته للسلة أو المفضلة.
- `/[locale]/categories/[slug]` — تصفح المنتجات التابعة لقسم رئيسي أو فرعي.
- `/[locale]/cart` — مراجعة سلة التسوق وتعديل الكميات.
- `/[locale]/checkout` — صفحة إتمام الطلب، اختيار المنطقة، خيارات الدفع ورفع الإيصال.
- `/[locale]/order-confirmation/[orderNumber]` — رسالة نجاح الطلب وتفاصيله المبدئية.
- `/[locale]/orders/[orderNumber]` — شاشة تتبع حالة الطلب وتفاصيل الشحنة.
- `/[locale]/favorites` — قائمة المنتجات المفضلة الخاصة بالمستخدم.
- `/[locale]/profile` — الملف الشخصي للعميل وإدارة البيانات الشخصية وسجل طلباته.
- `/[locale]/login` — تسجيل دخول العملاء.
- `/[locale]/register` — تسجيل حساب جديد لعميل.
- `/[locale]/page/[slug]` — صفحات المحتوى (من نحن `about`، التوصيل `delivery`، الأسئلة الشائعة `faq`).

### مسارات لوحة التحكم (`src/app/(admin)/admin`):
- `/admin-login` — بوابة تسجيل دخول المديرين.
- `/admin` — الصفحة الرئيسية للوحة التحكم والإحصائيات السريعة.
- `/admin/products` — استعراض، إضافة، تعديل، وترجمة وحذف المنتجات.
- `/admin/categories` — بناء وإدارة شجرة الأقسام والتصنيفات المتداخلة.
- `/admin/orders` — متابعة الطلبات، تحديث حالاتها، ومطابقة إيصالات الدفع.
- `/admin/inventory` — مراقبة المخزون وتعديل كميات المنتجات ومتغيراتها.
- `/admin/settings` — إعدادات المتجر العامة، حسابات البنك، مناطق الشحن ومحرك Best Route.
- `/admin/content` — إدارة نصوص صفحات "من نحن" و"التوصيل" والأسئلة الشائعة.

## 🚚 التكامل مع شركة الشحن (Best Route Integration)

تم تزويد متجر «رونق» بربط لوجستي متقدم مع نظام الشحن **Best Route**:
* **فحص الاتصال (Connection Check):** توفر لوحة الإدارة أداة تفاعلية لاختبار الاتصال بواجهة API الخاصة بشركة الشحن وعرض أنواع الطلبات والمناطق المعتمدة.
* **مناطق التغطية المدمجة:** يتضمن النظام لقطة مناطق جغرافية تشمل **65 منطقة ومحافظة** (الضفة، القدس، ومناطق الداخل).
* **إرسال الشحنات الآلي واليدوي:** تُرسل الشحنات إلى Best Route تلقائياً فور تأكيد الطلب، مع إمكانية إعادة المحاولة يدوياً من تفاصيل الطلب في حال حدوث أي خطأ في الاتصال.
* **آلية تسعير التوصيل والشحن الافتراضية:**
  - الضفة الغربية: 20 شيكل.
  - القدس: 30 شيكل.
  - مناطق الداخل: 70 شيكل.
  *(يمكن تعديل هذه الرسوم وتخصيص مناطق جديدة بحرية تامة من لوحة التحكم)*.
* **تسوية تكلفة الشحن:**
  - في حالة **الدفع عند الاستلام (COD)**: يقوم العميل بدفع أجرة التوصيل للمندوب عند استلام الطرد.
  - في حالة **التحويل البنكي**: تُسجل أجرة التوصيل على حساب المتجر لدى شركة الشحن؛ نظراً لأن العميل قد سددها مسبقاً ضمن إجمالي الفاتورة.

## ☁️ رفع الصور وتخزين الوسائط (Cloudinary)

* يتم رفع صور المنتجات مباشرة من لوحة التحكم عبر خادم مؤمّن إلى السحابة في **Cloudinary**.
* يدعم النظام الصور حتى حجم **5 ميغابايت** كحد أقصى لكل صورة.
* يتم تخزين رابط الصورة الآمن (Secure CDN URL) في قاعدة البيانات لتوفير أسرع تجربة تحميل لزوار المتجر.

## 🧩 الدمج في مشاريع قائمة (Monorepo / apps/web)

إذا كنت ترغب في دمج متجر رونق داخل بيئة عمل متعددة الحزم (Monorepo مثل Turborepo) أو في مجلد فرعي:
1. انسخ محتويات مجلدي `src/` و `public/` إلى مجلد تطبيق الويب لديك (مثلاً `apps/web/`).
2. ادمج الـ Root Layout من `src/app/layout.tsx` مع الـ Root Layout الحالي لمشروعك.
3. تأكد من تثبيت الحزم التابعة في `package.json` وخاصة `lucide-react`، `@prisma/client`، و `next-auth`.
4. انسخ ملف `prisma/schema.prisma` وقم بتوليد العميل عبر `npx prisma generate`.
