# رونق (RAWNQ) — متجر + لوحة تحكم (Next.js 14)

Next.js 14 (App Router) + React 18 + TypeScript + CSS Modules + lucide-react. بدون Tailwind.

## التشغيل
```bash
npm install
npm run db:push
npm run db:seed
npm run admin:create
npm run dev
npm test && npm run lint && npm run typecheck && npm run build
```

أضف القيم المطلوبة من `.env.example` إلى `.env.local` قبل التشغيل. استخدم رابط Supabase pooler في `DATABASE_URL` والرابط المباشر في `DIRECT_URL`. لا ترفع ملفات `.env` إلى Git.

## الصفحات (`src/app/[locale]/(store)`)
الرئيسية · المنتجات (بحث + فلتر قسم) · قسم `categories/[slug]` · المنتج مع اللون/الحجم · السلة · إتمام الطلب (Server Action) ·
تأكيد الطلب · طلباتي · تفاصيل الطلب · تسجيل الدخول · إنشاء حساب · صفحات المحتوى `page/[slug]` (من نحن، الأسئلة الشائعة، التوصيل).

**اللغات:** يدعم المتجر العربية (`/ar`)، والإنجليزية (`/en`)، والعبرية (`/he`)، والروسية (`/ru`) مع اختيار اللغة واتجاه عرض مناسب لكل لغة. تُدار ترجمات الأقسام والمنتجات ومناطق التوصيل وصفحات المتجر من لوحة الإدارة. بعد تحديث المخطط، شغّل `npm run db:push` لإضافة حقول الترجمة إلى قاعدة البيانات.

## لوحة التحكم (`/admin`)
الرئيسية · المنتجات (إضافة/تعديل/نشر/حذف + جدول اللون والحجم وترجمات اللغات) · الأقسام (ديناميكية: إضافة/تسمية/حذف وترجمة) · الطلبات وتفاصيلها بصور المنتجات وتغيير الحالة · المخزون · المحتوى والأسئلة الشائعة وترجماتها · الإعدادات (شحن، دفع، تنبيه المخزون).

**الأمان:** يستخدم تسجيل دخول العملاء والمديرين Auth.js وجلسات JWT؛ تُحمى `/admin` بإعادة التحقق من دور `ADMIN` في قاعدة البيانات. أنشئ المدير الأول عبر `npm run admin:create`؛ كلمة المرور (من 8 إلى 128 حرفاً) تُكتب مخفية في الطرفية ولا تُخزن إلا كتجزئة scrypt.

**البيانات:** الكتالوج والطلبات والمخزون والإعدادات والمحتوى والحسابات مخزنة في PostgreSQL عبر Prisma. إنشاء الطلب وخصم المخزون يتمان داخل معاملة واحدة. ارفع صور المنتجات من لوحة التحكم؛ الرفع يتم من الخادم إلى Cloudinary، مع حد 5 ميغابايت للصورة.

**Best Route:** أضف `BEST_ROUTE_LOGIN` و`BEST_ROUTE_PASSWORD` و`BEST_ROUTE_DB` و`BEST_ROUTE_ORDER_TYPE_ID` إلى `.env.local`. من إعدادات المتجر اضغط «فحص الاتصال» للتحقق من قوائم المناطق والمناطق الفرعية والحالات وأنواع الطلبات؛ الفحص يستخدم طلبات قراءة فقط ويعرض معرّفات أنواع الطلبات. مدن صفحة الدفع من لقطة `get_areas` المرفقة (65 منطقة). إنشاء الشحنة يدوي من تفاصيل الطلب، وليس عند إتمام العميل للشراء. قيمة البضاعة المرسلة هي المجموع الفرعي. في الدفع عند الاستلام، العميل يدفع أجرة التوصيل عند التسليم؛ وفي التحويل البنكي، يجب تأكيد وصول المبلغ أولاً، ثم تُسجل الأجرة على المتجر لأن العميل دفعها ضمن إجمالي المتجر. إذا انقطع الاتصال أثناء الإرسال، افحص Best Route برقم المرجع قبل المحاولة مجدداً. عند عدم وجود مناطق محفوظة في قاعدة البيانات، تستخدم الرسوم الافتراضية: الضفة 20 شيكل، القدس 30 شيكل، والداخل 70 شيكل. بعد تحديث Prisma schema، شغّل `npm run db:push` مرة واحدة لتطبيق حقول تتبع الشحن.

دخول الزبائن وإنشاء حساباتهم يستخدمان Auth.js Credentials بالبريد الإلكتروني وكلمة المرور، مع جلسات JWT وتجزئة scrypt لكلمات المرور.

تحقق من اتصال الخدمات باستخدام `npm run db:check`.

## للدمج في مشروعك الحالي (apps/web)
انسخ `src/` و`public/` فوق مشروعك، وادمج `src/app/layout.tsx` مع root layout الموجود، وأضف `lucide-react` إن لم يكن موجوداً.
