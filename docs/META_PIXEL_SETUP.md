# 📊 دليل إعداد وربط بيكسل ميتا (Meta Pixel & Conversions API) في متجر رونق

يقدم هذا الدليل شرحاً تفصيلياً وشاملاً لكيفية تفعيل وتكوين وتجربة بيكسل ميتا (**Meta Pixel**) وواجهة برمجة تطبيقات التحويلات من جانب الخادم (**Meta Conversions API - CAPI**) في متجر رونق (RAWNQ).

تم تجهيز المتجر ببنية تتبع متكاملة وفقاً لأحدث معايير Meta لعام 2026، وتدعم مطابقة الأحداث وإلغاء الازدواجية التلقائية (**Deduplication**) لمنع تكرار احتساب المبيعات.

## 1. نظرة عامة على أحداث التتبع المنفذة

تم ربط الأحداث القياسية (**Meta Standard Events**) في كامل رحلة العميل داخل المتجر:

| الحدث في Meta | أين يُطلق؟ | المعاملات والبيانات المرسلة | الغرض الإعلاني |
| :--- | :--- | :--- | :--- |
| **`PageView`** | تلقائياً عند زيارة أي صفحة وعند التنقل بين المسارات بالمتصفح | عنوان الصفحة ورابط الـ URL الحالي | تتبع حركة الزوار وبناء الجماهير المخصصة |
| **`ViewContent`** | عند فتح صفحة تفاصيل منتج محدد (`/products/[slug]`) | `content_ids`, `content_type: 'product'`, `content_name`, `value`, `currency: 'ILS'` | إعادة استهداف زوار منتجات محددة (Catalog Ads) |
| **`Search`** | عند إجراء بحث عن منتج في المتجر (`/products?q=...`) | `search_string`, `content_type: 'product'` | فهم رغبات واهتمامات المشترين |
| **`AddToCart`** | فور نجاح إضافة المنتج إلى سلة التسوق | `content_ids`, `content_name`, `value`, `currency`, `quantity` | إعادة استهداف أصحاب السلات المتروكة |
| **`RemoveFromCart`** | عند حذف منتج من سلة التسوق | `content_ids`, `content_name`, `value`, `currency`, `quantity` | تحليل المنتجات المحذوفة |
| **`InitiateCheckout`** | عند الدخول إلى شاشة إتمام الطلب وبدء عملية الشراء | `content_ids`, `contents`, `value`, `currency`, `num_items` | تحسين إعلانات الشراء وبدء الدفع |
| **`AddPaymentInfo`** | عند اختيار أو تغيير طريقة الدفع (الدفع عند الاستلام أو التحويل البنكي) | `value`, `currency`, `payment_type` | تتبع إتمام مرحلة الدفع |
| **`Purchase`** | **فقط** بعد حفظ الطلب بنجاح في قاعدة البيانات وظهور شاشة التأكيد | `content_ids`, `contents`, `value`, `currency`, `num_items`, `order_id`, `eventID` | قياس الإيرادات وعائد الإنفاق الإعلاني (ROAS) وتحسين التحويلات |

> [!IMPORTANT]
> **ضمان عدم تكرار حدث الشراء (Purchase):**
> لا يُطلق حدث الشراء نهائياً عند مجرد فتح صفحة الدفع أو الضغط على زر الإرسال. بل يُطلق فقط بعد أن يؤكد الخادم إنشاء الطلب في قاعدة البيانات، ويتم تخزين رقم الطلب محلياً لمنع إطلاق الحدث مرة أخرى عند إعادة تحميل الصفحة (**Page Refresh**) أو الرجوع إليها لاحقاً.

## 2. كيفية إنشاء بيكسل ميتا والحصول على المعرف (Pixel ID)

إذا لم يكن لديك بيكسل بعد، اتبع الخطوات التالية:

1. افتح **[Meta Events Manager (مدير أحداث ميتا)](https://business.facebook.com/events_manager2/)**.
2. تأكد من تحديد حساب الأعمال (**Meta Business Account**) الصحيح.
3. انقر على الزر الأخضر **Connect Data Sources (ربط مصادر البيانات)** في القائمة الجانبية.
4. اختر **Web (موقع الويب)** ثم اضغط **Connect (ربط)**.
5. أدخل اسماً للبيكسل (مثال: `RAWNQ Store Pixel`) واضغط **Create (إنشاء)**.
6. أدخل رابط موقع المتجر وانقر **Next**.
7. ستظهر لك شاشة الإعداد؛ يمكنك إغلاقها والانتقال إلى تبويب **Settings (الإعدادات)** الخاص بالبيكسل.
8. انسخ **Dataset ID / Pixel ID** (وهو عبارة عن رقم طويل، مثل `123456789012345`).

## 3. ضبط المتغيرات البيئية في `.env.local`

في المجلد الرئيسي للمشروع، أضف أو عدّل المتغيرات في ملف `.env.local`:

```env
# معرّف بيكسل ميتا للواجهة الأمامية (مطلوب لتفعيل التتبع في المتصفح)
NEXT_PUBLIC_META_PIXEL_ID=123456789012345

# معرّف البيكسل للخادم (اختياري، إن لم يُحدد يُستخدم المعرف السابق تلقائياً)
META_PIXEL_ID=123456789012345

# رمز الوصول لواجهة التحويلات من الخادم (CAPI) (اختياري للأمان والموثوقية العالية)
META_ACCESS_TOKEN=EAAG...your_long_token_here

# رمز اختبار الأحداث التجريبية (اختياري، يُستخدم فقط أثناء الفحص في Events Manager)
# META_TEST_EVENT_CODE=TEST12345
```

> [!TIP]
> إذا تُرك `NEXT_PUBLIC_META_PIXEL_ID` فارغاً، سيتوقف التتبع تلقائياً بدون أي أخطاء في المتصفح، مما يجعل المتجر يعمل بصورة طبيعية تماماً سواء في وضع التطوير المحلي أو الإنتاج.

## 4. إعداد واجهة التحويلات من الخادم (Conversions API - CAPI)

واجهة التحويلات من الخادم (**CAPI**) تضمن وصول أحداث الشراء بنسبة 100% حتى لو كان لدى العميل مانع إعلانات (**Ad Blocker**) أو متصفح يمنع ملفات تعريف الارتباط لطرف ثالث (مثل Safari ITP).

### للحصول على `META_ACCESS_TOKEN`:
1. في **Meta Events Manager**، افتح البيكسل الخاص بك.
2. انتقل إلى تبويب **Settings (الإعدادات)**.
3. مرر لأسفل إلى قسم **Conversions API (واجهة برمجة تطبيقات التحويلات)**.
4. في قسم **Set up direct integration**، اضغط على **Generate access token (إنشاء رمز وصول)**.
5. انسخ الرمز وضعه في متغير `META_ACCESS_TOKEN` داخل `.env.local`.

### ميزات الأمان والتشفير المنفذة في متجر رونق:
* **تشفير البيانات الحساسة (SHA-256 Hashing):** يتم تشفير البريد الإلكتروني، رقم الهاتف، والمدينة آلياً بواسطة خوارزمية SHA-256 قبل إرسالها إلى سيرفرات Meta وفق متطلبات الخصوصية العالمية.
* **حجب الرموز السرية:** لا يتم إظهار أو تسريب `META_ACCESS_TOKEN` إلى المتصفح أو في سجلات السيرفر أو استجابات الـ API إطلاقاً.
* **عدم التأثير على تجربة المشتري:** يتم إرسال طلب الـ CAPI في الخلفية بشكل لا تزامني (**Asynchronous**) حتى لا يتأخر توجيه العميل إلى شاشة تأكيد الطلب إطلاقاً.

## 5. كيفية عمل آلية منع التكرار وإلغاء الازدواجية (Event Deduplication)

عند تشغيل المتصفح والـ CAPI معاً، ستصل إشارة الشراء من مصدرين (المتصفح والسيرفر). لمنع فيسبوك من احتساب البيعة مرتين:

1. عند تأكيد الطلب، يقوم الخادم بتعيين معرّف حدث فريد:
   $$\text{event\_id} = \text{"order\_"} + \text{orderNumber}$$
2. يرسل المتصفح عبر البيكسل:
   ```javascript
   fbq('track', 'Purchase', { ...orderData }, { eventID: 'order_RQ-123456' });
   ```
3. ويرسل الخادم عبر CAPI:
   ```json
   {
     "event_name": "Purchase",
     "event_id": "order_RQ-123456",
     ...
   }
   ```
4. تقوم خوارزميات Meta بمطابقة `eventID` ودمج الإشارتين في عملية شراء واحدة مؤكدة ذات تصنيف جودة مرتفع (**High Event Quality Score**).

## 6. اختبار والتحقق من الأحداث (Testing & Validation)

### أ. الاختبار عبر إضافة المتصفح (Meta Pixel Helper):
1. ثبّت إضافة **[Meta Pixel Helper](https://chromewebstore.google.com/detail/meta-pixel-helper/fdgfkebogiimcoedlicjlajpkdmockpc)** على متصفح Google Chrome.
2. تصفح متجر رونق وتأكد من الآتي:
   - ظهور أيقونة البيكسل باللون الأخضر مع حدث `PageView`.
   - عند فتح أي منتج: ظهور حدث `ViewContent` مع سعر المنتج ومعرفه.
   - عند البحث: ظهور حدث `Search` مع نص البحث.
   - عند إضافة منتج للسلة: ظهور `AddToCart`.
   - عند الانتقال للدفع: ظهور `InitiateCheckout`.
   - عند تغيير وسيلة الدفع: ظهور `AddPaymentInfo`.
   - عند إتمام الطلب وظهور شاشة التأكيد: ظهور حدث `Purchase` بكامل القيمة ورقم الطلب.
   - جرب تحديث صفحة تأكيد الطلب (F5): **تأكد أن حدث Purchase لا يُطلق مرة ثانية**.

### ب. الاختبار عبر تبويب Test Events في Events Manager:
1. في **Events Manager**، افتح البيكسل واختر تبويب **Test Events (اختبار الأحداث)**.
2. بالنسبة لأحداث المتصفح: أدخل رابط متجرك واضغط **Open Website**.
3. بالنسبة لأحداث الخادم (CAPI): انسخ الرمز الظاهر في خانة Test Events وضع في `.env.local`:
   ```env
   META_TEST_EVENT_CODE=TEST12345
   ```
4. قم بعمل طلب تجريبي من المتجر؛ ستشاهد حدث `Purchase` يظهر فوراً في تبويب Test Events مع ظهور كلمة **Deduplicated (تم إلغاء الازدواجية)** وتفاصيل المتصفح والسيرفر معاً!

## 7. سياسة الخصوصية والموافقة على ملفات تعريف الارتباط (Cookie Consent)

تم تزويد متجر رونق بشريط موافقة ذكي لملفات تعريف الارتباط (`CookieConsent`):
* يظهر تلقائياً في أسفل المتجر للزوار الجدد بجميع اللغات الأربع (**العربية، الإنجليزية، العبرية، والروسية**) وباتجاه نصوص متطابق (**RTL / LTR**).
* عند الضغط على **موافق**: يتم منح الإذن عبر `fbq('consent', 'grant')` وحفظ الخيار في `localStorage`.
* عند الضغط على **رفض**: يتم إيقاف التتبع الإعلاني عبر `fbq('consent', 'revoke')`.

## 8. الأسئلة الشائعة وحل المشكلات

### س: كيف أعرف أن البيكسل متوقف ولا يعمل؟
إذا لم تقم بوضع `NEXT_PUBLIC_META_PIXEL_ID` في `.env.local`، فلن يتم حقن سكربت البيكسل نهائياً في الصفحة ولن يظهر أي كود في مصدر الصفحة.

### س: هل يؤثر البيكسل على سرعة تحميل المتجر؟
لا؛ يتم تحميل سكربت البيكسل باستراتيجية `afterInteractive` الخاصة بـ Next.js، مما يضمن تحميل كافة عناصر واجهة المتجر وصور المنتجات أولاً بأعلى سرعة دون أي تأخير في الـ First Contentful Paint (FCP).

### س: ما هي العملة المعتمدة في الأحداث؟
العملة المعتمدة رسمياً في جميع أحداث الشراء وسلة المشتريات هي الشيكل الإسرائيلي الجديد كود: `ILS` (₪)، وهو المعيار المدعوم عالمياً من أنظمة إعلانات Meta.
